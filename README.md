# 《和牌》

麻将主题 · 牌组构筑 Roguelike · H5 游戏

2~6 张灵活出牌 × 14 档牌型 × 番数倍率构筑。用麻将的组牌结构和番种体系，重做《小丑牌》的「点数 × 番数」爽感循环。

## 跑起来

```bash
python -m http.server 8080 --directory .
```

然后打开 http://127.0.0.1:8080

纯静态、零构建、无依赖。也可以直接双击 `index.html`，但 `file://` 下部分浏览器会禁用 localStorage，导致存档不可用。

## 玩法

1. 选难度（东风局每种 4 张 / 南风局 3 张 / 西风局 2 张）
2. 从 13 张手牌里点选 **2~6 张**——多打多得分，少打留牌
3. 看预览确认牌型和预估得分，点「和牌」
4. 拿不准就点「提示」——每局 6 次，自动打出手里分值最高的组合
5. 出牌次数用完还没达标就流局；过关进商店买牌灵和香火
6. 打完 8 圈可以**继续挑战无尽模式**

### 几个特殊机制

- **宝牌**：每关随机指定，牌面金色高亮 + 「宝」字，打出每张 +3 番
- **听牌**：每关一次，选一个手里没有的牌作听口，3 回合内命中番数 ×3
- **刻上开花**：打出含 3 张以上相同时，本手 +2 番并永久 +1 番（上限 +3）
- **老虎机**：每圈免费摇一次，3 张牌灵全拿走，**同名自动合并**成「二重」或「满贯」

## 验证

```bash
# 安装仅测试用的 Playwright 依赖
npm install

# 牌型、计分、经济与获取路径自测（76 项）
npm test

# 批量模拟：三档难度各 N 局
node tools/sim/batch.js 300 east seed=20261019

# 浏览器走查（支持 macOS/Linux/Windows 本机 Chrome）
npm run test:ui
```
